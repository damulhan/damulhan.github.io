# 파이썬 입력

파이썬 프로그래밍에서 명령줄 입력(키보드 사용)은 input() 메서드(파이썬 3) 또는 raw_input() 메서드(파이썬 2)를 사용하여 받을 수 있습니다. 여기서는 키보드 입력을 받기 위해 첫 번째 방법을 사용하겠습니다.

# 예제 1

다음 예제는 input() 메서드를 사용하여 두 개의 정수를 더하는 것을 보여줍니다:

# Input test for integer numbers
x = input("Enter value of a: ")
a = int(x)
y = input("Enter value of b: ")
b = int(y)
sum = a + b;
print("\nSUM:", sum)

출력:

Enter value of a: 10

Enter value of b: 20

SUM: 30

# 예제 2

다음 예는 input() 메서드를 사용하여 두 개의 부동 소수점 숫자를 더하는 것을 보여줍니다:

# Input test for floating-point numbers
x = input("Enter value of a: ")
a = float(x)
y = input("Enter value of b: ")
b = float(y)
sum = a + b;
print("\nSUM:", sum)

출력:

Enter value of a: 12.3

Enter value of b: 23.2

SUM: 35.5
